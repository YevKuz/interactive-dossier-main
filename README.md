# Interactive Dossier

A bilingual personal dossier for Evgeny Kuzmin, built with React, TanStack Start, and Vite.

## Run locally

Install [Node.js](https://nodejs.org/) (which includes npm), then from this folder run:

```sh
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). The local development server refreshes the
browser as you edit the source files. Stop it with `Ctrl+C` in the terminal.

The server listens only on this computer. It does not publish the site to the internet.

## Deploy to GitHub Pages

Pushing to `main` builds and deploys the site to
[https://YevKuz.github.io/interactive-dossier-main/](https://YevKuz.github.io/interactive-dossier-main/)
using GitHub Actions. In the repository settings, set **Pages → Build and deployment → Source** to
**GitHub Actions**.
